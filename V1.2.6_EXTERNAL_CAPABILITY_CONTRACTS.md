# v1.2.6 external capability contracts

This release contains fail-closed server adapters; no local substitute is used for OCR, embeddings, vector search, arbitrary execution, or JavaScript rendering. All URLs and tokens are **server-side Render/worker variables**. Do not expose them as `VITE_*` values.

## Private OCR service

Enable only after a controlled private OCR deployment accepts:

```text
KNOWLEDGE_OCR_ENABLED=true
KNOWLEDGE_OCR_SERVICE_URL=https://private-ocr.example/v1-base
KNOWLEDGE_OCR_SERVICE_TOKEN=server-secret
KNOWLEDGE_OCR_TIMEOUT_MS=30000
KNOWLEDGE_OCR_MAX_PAGES=150
KNOWLEDGE_OCR_MAX_IMAGE_BYTES=8388608
```

`POST /v1/ocr` receives one JSON document `{document:{filename,contentType,checksum,bytesBase64}, policy:{maxPages,returnPageText,preservePageOrder}}`. It must return a page-ordered `{status:"completed"|"partial", engine, engineVersion, pageCount, pages:[{pageNumber,text,status,confidence?}], notices?}` response. Only PDF, PNG, JPEG and WebP are sent. Original objects remain private; page text, page status, OCR engine/version and content hashes are persisted for citation provenance.

## Embedding and vector services

```text
KNOWLEDGE_SEMANTIC_ENABLED=true
KNOWLEDGE_EMBEDDING_SERVICE_URL=https://private-embeddings.example
KNOWLEDGE_EMBEDDING_SERVICE_TOKEN=server-secret
KNOWLEDGE_EMBEDDING_MODEL=operator-verified-model-id
KNOWLEDGE_VECTOR_STORE_URL=https://private-vector-gateway.example
KNOWLEDGE_VECTOR_STORE_TOKEN=server-secret
KNOWLEDGE_VECTOR_COLLECTION=voicechatglm_private_knowledge
KNOWLEDGE_SEMANTIC_TIMEOUT_MS=20000
KNOWLEDGE_EMBEDDING_BATCH_SIZE=32
```

The embedding service implements OpenAI-compatible `POST /v1/embeddings` with `data[index,embedding]`. The private vector gateway implements `POST /v1/vectors/upsert`, `/query`, and `/delete`, always takes a server-set `namespace` equal to the authenticated user UUID, and must not permit client-selected namespaces. v1.2.6 stores only vector ID, content hash, model, model version, dimensions and lifecycle metadata in PostgreSQL. Hybrid retrieval uses reciprocal-rank fusion; unavailable/failed semantic retrieval is reported as lexical or lexical fallback, never as semantic.

## Isolated custom analysis

```text
ISOLATED_ANALYSIS_ENABLED=true
ISOLATED_ANALYSIS_SERVICE_URL=https://private-sandbox.example
ISOLATED_ANALYSIS_SERVICE_TOKEN=server-secret
ISOLATED_ANALYSIS_TIMEOUT_MS=30000
ISOLATED_ANALYSIS_MAX_CODE_CHARACTERS=12000
```

`POST /v1/execute` must run in a separately hosted isolation boundary and return `{status:"completed",summary,output:{format:"json"|"csv"|"txt"|"md",content,title?}}`. The requested policy requires no network, ephemeral filesystem, no process spawn, JSON-only result, and a 1 MB output maximum. This Node application never evaluates, imports, or forks user/model code. Verify the deployed sandbox's VM/container boundary and egress policy independently before enabling it.

## Browser renderer

```text
BROWSER_RENDERING_ENABLED=true
BROWSER_RENDERER_SERVICE_URL=https://private-browser-renderer.example
BROWSER_RENDERER_SERVICE_TOKEN=server-secret
BROWSER_RENDERER_EGRESS_ENFORCED=true
BROWSER_RENDERER_TIMEOUT_MS=30000
BROWSER_RENDERER_MAX_REDIRECTS=3
BROWSER_RENDERER_MAX_TEXT_CHARS=40000
```

`POST /v1/render` receives one public credential-free URL and a policy requiring private-network/local-host denial, DNS resolution-and-pinning at each redirect, no credentials, bounded redirects and response bytes. The renderer must return `{status:"completed",finalUrl,redirects,title,text,networkPolicy:{deniedPrivateNetworks:true,resolvedAndPinnedEveryHop:true,noCredentialsSent:true}}`. v1.2.6 validates every original/final/redirect URL and rejects any missing attestation. It does not call conventional HTTP extraction as a browser-rendering fallback.

## Worker deployment

`render.yaml` declares the separately hosted Render worker service. Give it the same private PostgreSQL/object-store configuration as the API, but never public routing. It leases PostgreSQL jobs and may run multiple replicas. Configure OCR and semantic variables on the worker only after their service acceptance passes.
