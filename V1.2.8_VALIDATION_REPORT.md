## Controlled functionality proven locally

1. **Renderer/engine:** `pdfjs-dist@5.4.149` plus `@napi-rs/canvas@0.1.100` rasterized the scanner-safe fixture. `tesseract.js@5.1.1` plus packaged `@tesseract.js-data/eng@1.0.0` recognized `VOICECHAT OCR 2026`.
2. **Mixed PDF selection:** a native page returned `native_text` (`NATIVE MIXED PAGE 2028`) and only the scanned page returned `ocr`, in original page order.
3. **Bounds/lifecycle:** blank, malformed, page-limit, cancellation, worker initialization failure, timed-out recognition, queued cancellation, and PDF smoke readiness have controlled tests. The OCR worker cap defaults to 1 and is constrained to 1–4.
4. **Shared integration:** scanner-clean chat attachments cache the protected extraction artifact only when submitted for analysis; scanner-unclean attachments are refused before object reads. The Knowledge worker independently rechecks status and indexes ordered mixed-PDF provenance through the same processor.
5. **Redaction/prompt safety:** page text is redacted or excluded before page hashes, private extraction artifacts, Knowledge chunks, and model evidence. Existing bounded untrusted-evidence delimiters remain in the model path.

## Deliberately not represented as proven

- Malware scanning, storage quarantine/promote/delete, database ownership enforcement, Redis rate limiting, Knowledge leases/retries/deletion races, and model payloads against real services.
- Render native module installation/startup/resource sizing; Netlify API/CORS/cookie/browser UX; browser cancellation behavior; actual capability/readiness response from deployed infrastructure.
- Any OCR quality, language support, or visual understanding beyond the supplied English typed-text fixtures.
- Model revision availability or inference success. The protected model identifier/revision was retained, not contacted, replaced, uploaded, retrained, fine-tuned, merged, self-hosted, or exposed.
